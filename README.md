# FastFood Telegram Bot 🍔

A Telegram bot built with Python and aiogram that helps users browse a food menu and manage their orders in Uzbek.

## Features
- View the food menu
- Place orders
- Cancel orders
- Uzbek-language interface

## Technologies
- Python
- aiogram
- SQLite

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Durdona57/fastfood-tg-bot.git
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Configure your bot token in a `.env` file.
4. Run the bot:
   ```bash
   python main.py
   ```
